# 🦠 COVID-19 Data Analysis

A data analysis project focused on understanding COVID-19 trends across different countries using Python, Pandas, Matplotlib, Jupyter Notebook, and Tableau.

## 📌 Project Overview

This project analyzes COVID-19 data to understand the spread of the pandemic, mortality rates, vaccination coverage, and case trends across multiple countries.

The data was cleaned and transformed using Python and Pandas, followed by exploratory analysis and visualization. Tableau was used to create an interactive dashboard for presenting the key findings.

## 🎯 Objectives

- Analyze total COVID-19 cases across countries
- Analyze total COVID-19 deaths
- Calculate and compare mortality rates
- Analyze vaccination coverage
- Identify COVID-19 case trends using 7-day rolling averages
- Compare total cases with population
- Present insights through clear and interactive visualizations
