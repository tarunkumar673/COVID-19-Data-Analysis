# COVID-19 Data Analysis

This project analyzes COVID-19 data using Python, Pandas, Matplotlib, and Tableau.

## Key Analysis
- COVID-19 cases by country
- COVID-19 deaths by country
- Mortality rate analysis
- Vaccination coverage
- 7-day rolling average case trends
- Cases vs population analysis

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Tableau

## Project Objective
The objective of this project is to clean, analyze, and visualize COVID-19 data to identify trends and communicate key insights through data visualization.
